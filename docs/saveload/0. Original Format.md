Tiberian Dawn (and Red Alert) use a binary format for saving the game state to a file. This consists of dumping the memory of object pointers and some metadata (array counts, scenario info etc.).

A big positive of this approach was the ability to share custom missions etc. using a save game, rather than having to share the INI and BIN file for the scenario.

However, the main drawbacks of this approach are:

- **Portability**
    - If a save is made on a build of the game using one platform (runtime/compiler) there is no guarantee that the layout of objects in memory will be the same on another platform when load is attempted
    - This is even more broken if transferring a save between big endian and little endian systems (although big endian platforms are rare)
- **Game Version Compatibility**
    - Save games are directly tied to several factors in the game code (enum values, order of field declarations in C++ classes, size of arrays etc.)
    - C&C protects against this somewhat by building a version number that ensures sizes of objects and scenario metadata variables are the same (although no protection against field declaration order)
    - This means saves from older versions of the games are not supported (no backwards compatibility)
    - For modding, this means any changes to the code (like refactoring classes to add new fields, adding new units etc.) keep breaking old saves
- **Proprietary Format**
    - Without having intimate knowledge of the structure of a save game and the objects/fields being serialised it's very difficult to open a save game file and read information/make changes
## Pointer Handling

Object
- The heaps maintained by the game hold the actual objects (units, terrain etc.)
- Other objects and game logic reference objects using pointers to items in the heap
Game Types
- Type classes (`UnitTypeClass` etc.) are static objects initialised on game startup 
- Objects in the heap reference these using pointers

To manage these pointers the save logic:

- Calls the `Code_All_Pointers` function, which bubbles through to all object instances to call a method with the same name
- This replaces pointers to objects and type class objects with a TARGET, which is a number that can be decomposed into two variables: KIND and ID (stored in the address storage of the pointer)
- When loading, the `Decode_All_Pointers` function will do the reverse and lookup objects in heaps and the static type class objects by the ID stored and point to the correct instance
## Structure

The binary save format follows the below structure:

| Data                                       | Type                         | Notes                                                                     |
| ------------------------------------------ | ---------------------------- | ------------------------------------------------------------------------- |
| Scenario Description                       | char*                        | Length of `DESCRIP_MAX`                                                   |
| Scenario ID                                | int                          | -                                                                         |
| House Type                                 | signed char                  | -                                                                         |
| Save Game Version                          | unsigned int                 | Macro defined by `SAVEGAME_VERSION`                                       |
| Map                                        | `MouseClass` values          | Written by `MouseClass::Save` method                                      |
| Houses                                     | `TFixedIHeapClass` heap      | Written by `TFixedIHeapClass<T>::Save` method                             |
| TeamTypes                                  | ""                           | ""                                                                        |
| Teams                                      | ""                           | ""                                                                        |
| Triggers                                   | ""                           | ""                                                                        |
| Aircraft                                   | ""                           | ""                                                                        |
| Anims                                      | ""                           | ""                                                                        |
| Buildings                                  | ""                           | ""                                                                        |
| Bullets                                    | ""                           | ""                                                                        |
| Infantry                                   | ""                           | ""                                                                        |
| Overlays                                   | ""                           | ""                                                                        |
| Smudges                                    | ""                           | ""                                                                        |
| Tempates                                   | ""                           | ""                                                                        |
| Terrains                                   | ""                           | ""                                                                        |
| Units                                      | ""                           | ""                                                                        |
| Factories                                  | ""                           | ""                                                                        |
| Game Logic                                 | `LayerClass` values          | Written by `LayerClass::Save` method                                      |
| Map Layers                                 | Array of `LayerCLass` values | Length of `LAYER_COUNT` - each entry Written by `LayerClass::Save` method |
| Game Score                                 | `ScoreClass` values          | Written by `ScoreClass::Save` method                                      |
| AI Base                                    | `BaseClass` values           | Written by `BaseClass::Save` method                                       |
| Player Pointer                             | signed char                  | Coded pointer to `HouseClass` holding a `HousesType` enum value           |
| Scenario Number                            | int                          | Pulled from global instance `Scen` of `ScenarioClass`                     |
| Player Difficulty                          | unsigned char                | ""                                                                        |
| AI Difficulty                              | unsigned char                | ""                                                                        |
| Frame                                      | int                          | -                                                                         |
| Win Movie                                  | char*                        | 262 characters in length (excluding `\0`)                                 |
| Lose Movie                                 | ""                           | ""                                                                        |
| Selected Objects                           | `SelectedObjectsType` values | -                                                                         |
| Waypoints                                  | signed short*                | Array of 28 CELL values (alias for signed short)                          |
| Scenario Direction                         | signed char                  | -                                                                         |
| Scenario Variation                         | signed char                  | -                                                                         |
| Carry Over Money                           | int                          | -                                                                         |
| Carry Over Percent                         | int                          | -                                                                         |
| Build Level                                | unsigned int                 |                                                                           |
| Briefing Movie                             | char*                        | 262 characters in length (excluding `\0`)                                 |
| Map Bookmarks                              | signed short*                | Array of 4 CELL values (alias for signed short)                           |
| Scenario End Countdown                     | int                          | -                                                                         |
| Briefing Text                              | char*                        | 511 characters (excluding `\0`)                                           |
| Action Movie                               | char*                        | 262 characters in length (excluding `\0`)                                 |
| Has Temple of Nod been hit with Ion Cannon | bool                         | -                                                                         |
| Are 'Thingies' enabled                     | bool                         | -                                                                         |
