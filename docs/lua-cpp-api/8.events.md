# LuaEvent Class

The `LuaEvent` class is an abstract base class all Lua Events should extend.

A concrete subclass should data using private fields and logic by implementing the overriding the virtual method `Execute`.

Here is an example implementation:

```c++
class ExampleLuaEvent : public LuaEvent
{
public:
    ExampleLuaEvent(int data) : LuaEvent("Example")
    {
        Data = data;
    }

    virtual void Execute() const override
    {
        LuaEvent::Execute();

        CNC_LOGGER_INFO("I have data: {}", Data);
    }

private:
    int Data;
};

```

## Motivation

Events are are a way to separate out the request to preform an action and actually executing that action. This is useful primarily for thread safety, as the game engine should own the time of execution.

## Intended flow

It is intended in a game engine that:

- Lua APIs will create event instances in response to Lua calls and pass these to the game engine
- The game engine should buffer events received from Lua
- When the game engine is ready to process Lua events, it should execute events one at time, in the order they were received - then discard the events
- The game engine should block new events being buffered whilst it is processing existing events

Typically it is intended this be achieved with the `AtomicQueue` class.
