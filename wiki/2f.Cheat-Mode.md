You can run the game in a 'cheat' mode, which is basically the regular game but with a bunch of keyboard shortcuts to change the game in some way. Most of these are leftover code from the original Westwood developers used to debug the games.

**Note: Only Tiberian Dawn is supported for now**

## Tiberian Dawn Cheat Mode

To start the game in 'cheat' mode:

- Open the NCO game folder
- Find `nco-td-cheats` and run it instead of the main game
  - This might be `nco-td-cheats.bat` (Windows) or `nco-td-cheats.sh` depending on your OS

> You can also use cheat mode by running the game with the `-CHEAT` cli argument: `nco-td -CHEAT`

### Keys

 Key | Note |
|-----|------|
| F3 | Toggle Debug Map Mode |
| F5 | Execute Lua Script `__debug.lua` (if it exists) |
| DELETE | Remove currently selected object |
| ` (backtick) | Damage objects under cursor |
| / | Show special options dialog (**Note:** Only works in Skirmish/Network game for now) |
| C | Allow building any standard object (Pre-requisites are still required - restart game to disable) |
| Z | Run GDI ending sequence |
| O | Spawn an orca |
| CTRL + M | Give Player $10K |
| ALT + B | Instant builds (press again to disable) |
| ALT + Z | Toggle between making the map maximum size and original size |
| ALT + W | Win |
| ALT + L | Lose |
| SHIFT + DELETE | Damage the currently selected object |

> There are more keys in the source code, but these either don't work or cause the game to crash
