`rules.ini` is a simple text file that controls how different units, buildings and infantry behave in-game. This was included by default by Westwood in Red Alert onward. Below is a explaination of the sections in this file and different values that can be set.

The `rules.ini` file is created for you when you first run the game, and can be found where you installed `vanillatd` and the required game files.

## Game

These sections contain a list of 'switches' for turning certain hard-wired game logic on/off. Set a switch value to `yes` to turn it on and `no` to turn it off. All values in the default RULES.INI file are the defaults from the original source code.

### [Game.Map]

```ini
[Game.Map]
MaxBuildDistance=1
; ...
```

| Switch | Notes |
|--------|-------------|
| `MaxBuildDistance` | This controls how far away from an existing structure a player can place a building. _Note: values higher than 6 may cause performance problems._ |
| `PreventBuildingInShroud` | (**NOTE: Broken**) Prevent a player from placing a building inside the shroud/fog of war. |
