If you are brave and want to try building this yourself, this guide will help you do that.

## Before you start

Ensure you have the following installed:

- A C++ toolchain (gcc, clang, msvc) <!-- TODO: More precise guidance -->
  - On Windows: use Visual Studio Community (C++ guide [here](https://learn.microsoft.com/en-us/cpp/overview/visual-cpp-in-visual-studio?view=msvc-170))
- CMake
- Git
- Bash (On Windows use Git Bash)
- On Linux, some `libtool` headers are required
  - Install a package similar to [libltdl-dev](https://launchpad.net/ubuntu/noble/+package/libltdl-dev) on Ubuntu
  - Example: `sudo apt-get install -y libltdl-dev`

## Run the build

- Clone this repo
- Open a Terminal (Use Git Bash on Windows)
- Ensure `vcpkg` is initialized:
  - On windows: `IS_WINDOWS=true ./scripts/bin/vcpkg --init`
  - Everywhere else: `./scripts/bin/vcpkg --init`
- Build using cmake: `cmake --workflow --preset nco`
- You can find the binaries in `build/nco/RelWithDebInfo`
  - Tiberian Dawn: `vanillatd`
  - Red Alert: `vanillara`
- If you need help installing the data files for the games, see:
  - [Tiberian Dawn](https://github.com/TheAssemblyArmada/Vanilla-Conquer/wiki/Installing-VanillaTD)
  - [Red Alert](https://github.com/TheAssemblyArmada/Vanilla-Conquer/wiki/Installing-VanillaRA)

> For more help, you can refer to the [Vanilla Conquer Build Guide](https://github.com/TheAssemblyArmada/Vanilla-Conquer/wiki/Compiling-Vanilla-Conquer#configuring-the-build)
