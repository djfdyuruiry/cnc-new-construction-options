This guide will help you build NCO from source.

## Before you start

At a high level, you must have the following tools:

- C++ toolchain
  - `clang` is recommended, but `gcc` and `msvc` are also supported
- CMake
- Ninja
- Git
- Bash (_Provided by Git for Windows_)
- ImageMagick

See the below guides for specific guidance for your Operating System.

> **Note**: It's always recommended to restart your terminal at the end of the below steps, so that all tools are in your PATH

### Linux

Some package manager dependencies are required on Linux:

- C++ Toolchain and supporting tools
  - Ubuntu example (clang):
    ```shell
    sudo apt-get install -y autoconf \
      autoconf-archive \
      automake \
      build-essential \
      cmake \
      clang \
      curl \
      git \
      ninja-build \
      pkg-config \
      python3 \
      python3-jinja2 \
      tar \
      unzip \
      zip
    ```
- ImageMagick binaries
  - Ubuntu example: `sudo apt-get install imagemagick`
- Development packages for X11 and Wayland
  - X11 package guidance is [here](https://github.com/microsoft/vcpkg/blob/16852ae1a4c7bcc1b4a597ddd6b4e4776361aba8/ports/sdl2/portfile.cmake#L29)
    - Ubuntu example: `sudo apt install libx11-dev libxft-dev libxext-dev`
  - Wayland package guidance is [here](https://github.com/microsoft/vcpkg/blob/16852ae1a4c7bcc1b4a597ddd6b4e4776361aba8/ports/sdl2/portfile.cmake#L32)
    - Ubuntu example: `sudo apt install libwayland-dev libxkbcommon-dev libegl1-mesa-dev`
- `libtool` headers
  - Ubuntu example: `sudo apt-get install -y libltdl-dev`
  - See: [libltdl-dev](https://launchpad.net/ubuntu/noble/+package/libltdl-dev)

### Windows

- Install Git for Windows from [here](https://gitforwindows.org/)
- Install Visual Studio Community 2022 with C++ tools, full guide [here](https://learn.microsoft.com/en-us/cpp/build/vscpp-step-0-installation?view=msvc-170)
  - Make sure you select `Desktop development with C++` when following the guide
- Install required build tools using `winget` (_included in the latest version of Windows 10 and 11 by default_)
  - _If you can't run the below commands on Windows 10, check the docs [here](https://learn.microsoft.com/en-us/windows/package-manager/winget/#install-winget)_
  - `winget install -e --id ImageMagick.ImageMagick`
  - `winget install -e --id Kitware.CMake`
  - `winget install -e --id Ninja-build.Ninja`

### MacOS

- Install XCode and XCode Command Line Tools
  - Doing this will also provide `git`
- Use MacPorts or Homebrew to install required build tools
  - Homebrew example: `brew install dylibbundler imagemagick jinja2-cli jq ninja python3`

## Run the build

- Open a Terminal
  - If you are on Windows, open a PowerShell Window and run:
    ```pwsh
      & "$(& "${Env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe" -products * -latest -property installationPath)\Common7\Tools\Launch-VsDevShell.ps1" -Arch amd64 -SkipAutomaticLocation
    ```
- Clone this repo and `cd` into it:
  - `git clone https://github.com/djfdyuruiry/cnc-new-construction-options.git`
  - `cd cnc-new-construction-options`
- Ensure `vcpkg` is initialized:
  - On windows: `scripts/bin/vcpkg.ps1 --init`
  - Everywhere else: `./scripts/bin/vcpkg --init`
- Setup the CMake environment:
  - On Windows:
    ```pwsh
    $env:CMAKE_MAKE_PROGRAM="ninja"
    $env:CMAKE_FIND_ROOT_PATH="$(Split-Path -Path $(Get-Command magick).Path -Parent)"
    $env:VC_CXX_FLAGS="/Zc:strictStrings;-wd4244;-wd4018;-wd4291;-wd4101;-wd4267;-wd4200;-wd4828"
    ```
  - Everywhere else:
    ```shell
    export CMAKE_MAKE_PROGRAM="ninja"

    # you can specify another C++ toolchain here
    export CC="clang"
    export CXX="clang++"
    ```
- Build using cmake: `cmake --workflow --preset nco`
- You can find binaries and extra files for each game in `build/nco/RelWithDebInfo`:
  - Tiberian Dawn:
    - Open the `td` directory
    - Linux binary: `vanillatd`
    - Windows exe: `vanillatd.exe`
    - MacOS app bundle: `vanillatd.app`
  - Red Alert
    - Open the `ra` directory
    - Linux binary: `vanillara`
    - Windows exe: `vanillara.exe`
    - MacOS app bundle: `vanillara.app`
- If you need help installing the data files for the games, see:
  - [Tiberian Dawn](https://github.com/TheAssemblyArmada/Vanilla-Conquer/wiki/Installing-VanillaTD)
  - [Red Alert](https://github.com/TheAssemblyArmada/Vanilla-Conquer/wiki/Installing-VanillaRA)

> For more help, you can refer to the [Vanilla Conquer Build Guide](https://github.com/TheAssemblyArmada/Vanilla-Conquer/wiki/Compiling-Vanilla-Conquer#configuring-the-build)
