## Before you start

At a high level, you must have the following tools:

- C++ toolchain
  - `clang` is recommended, but `gcc` and `msvc` are also supported
- CMake
- Ninja
- Git
- Bash (_Provided by Git for Windows_)
- ImageMagick

See the below guides for specific guidance for your Operating System.

> **Note**: It's always recommended to restart your terminal at the end of the below steps, so that all tools are in your PATH

### Linux

> A docker build is available that targets Ubuntu, see [Docker](#docker)

Some package manager dependencies are required on Linux:

- C++ Toolchain and supporting tools
  - Ubuntu example (`clang`):
    ```shell
    sudo apt-get install -y autoconf autoconf-archive automake bison build-essential cmake clang curl git ninja-build pkg-config python3 python3-jinja2 tar unzip zip
    ```
- ImageMagick binaries
  - Ubuntu example: `sudo apt-get install imagemagick`
- Development packages for X11 and Wayland
  - X11 package guidance is [here](https://github.com/microsoft/vcpkg/blob/16852ae1a4c7bcc1b4a597ddd6b4e4776361aba8/ports/sdl2/portfile.cmake#L29)
    - Ubuntu example: `sudo apt install libx11-dev libxft-dev libxext-dev`
  - Wayland package guidance is [here](https://github.com/microsoft/vcpkg/blob/16852ae1a4c7bcc1b4a597ddd6b4e4776361aba8/ports/sdl2/portfile.cmake#L32)
    - Ubuntu example: `sudo apt install libwayland-dev libxkbcommon-dev libegl1-mesa-dev`
- `libtool` headers
  - Ubuntu example: `sudo apt-get install -y libltdl-dev`
  - See: [libltdl-dev](https://launchpad.net/ubuntu/noble/+package/libltdl-dev)

### Windows

- Use a package manager like Winget or Chocolatey to install required tools easily.
- Chocolatey example:
  - Install Chocolatey: https://chocolatey.org/install
  - Open powershell as an administrator and run:
    - Visual Studio 2022 and C++ Desktop Tools: `choco install visualstudio2022community visualstudio2022-workload-nativedesktop`
    - CMake, Ninja and Git: `choco install cmake ninja git`
    - ImageMagick: `choco install imagemagick`

### MacOS

> **NOTE -** if you are having issues building on mac, use a newer version of Clang by installing the [llvm](https://formulae.brew.sh/formula/llvm) homebrew package and setting up your `PATH`

- Install XCode and XCode Command Line Tools
  - Doing this will also provide `git`
- Use MacPorts or Homebrew to install required build tools
- Homebrew example:
  - Install homebrew: https://brew.sh/
  - Open a terminal and run: `brew install bison cmake dylibbundler imagemagick jinja2-cli jq ninja python3`

## Run the build

- Open a Terminal
  - If you are on Windows, open a PowerShell Window and run:
    ```pwsh
      & "$(& "${Env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe" -products * -latest -property installationPath)\Common7\Tools\Launch-VsDevShell.ps1" -Arch amd64 -SkipAutomaticLocation
    ```
	- You can change `amd64` in the above example if you want to target another architecture (e.g. x86)
- Clone this repo and `cd` into it:
  - `git clone https://github.com/djfdyuruiry/cnc-new-construction-options.git`
  - `cd cnc-new-construction-options`
- Ensure `vcpkg` is initialized:
  - On windows: `scripts/bin/vcpkg.ps1 --init`
  - Everywhere else: `./scripts/bin/vcpkg --init`
- Set up the CMake environment:
  - On Windows:
    ```pwsh
    $env:CMAKE_MAKE_PROGRAM="ninja"
    $env:CMAKE_FIND_ROOT_PATH="$(Split-Path -Path $(Get-Command magick).Path -Parent)"
    ```
  - Everywhere else:
    ```shell
    # you can specify another generator here, if needed
    export CMAKE_MAKE_PROGRAM="ninja"

    # you can specify another C++ toolchain here, if needed
    export CC="clang"
    export CXX="clang++"
    export CMAKE_C_COMPILER="clang"
    export CMAKE_CXX_COMPILER="clang++"
    ```
- Build using cmake: `cmake --workflow --preset release`
- You can find binaries and extra files for each game in `build/release/RelWithDebInfo`:
  - Tiberian Dawn:
    - Open the `td` directory
    - Linux binary: `nco-td`
    - Windows exe: `nco-td.exe`
    - MacOS app bundle: `nco-td.app`
  - Red Alert
    - Open the `ra` directory
    - Linux binary: `nco-ra`
    - Windows exe: `nco-ra.exe`
    - MacOS app bundle: `nco-ra.app`
- Use the [NCO Launcher](1.Launcher.md) to install data files for the games
  - On Windows/Linux: Copy your binaries to the NCO install directory shown in the launcher
  - On macos: Follow the guidance on the launcher page to install your app bundle

## Remastered Mod

You can build New Construction Options as a mod for the [Command & Conquer Remastered](https://www.ea.com/games/command-and-conquer/command-and-conquer-remastered) game.

**Note: Windows is required to build the mod DLLs**

Here are the steps to follow:

- Follow the [Windows](#windows) section above to get build tools installed
- Open powershell (use search on the Start Menu)
- Run:
    ```pwsh
      & "$(& "${Env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe" -products * -latest -property installationPath)\Common7\Tools\Launch-VsDevShell.ps1" -Arch x86 -SkipAutomaticLocation
    ```
- Clone this repo and `cd` into it:
  - `git clone https://github.com/djfdyuruiry/cnc-new-construction-options.git`
  - `cd cnc-new-construction-options`
- Ensure `vcpkg` is initialized by running: `scripts/bin/vcpkg.ps1 --init`
- Set up the CMake environment by running:
    ```pwsh
    $env:CMAKE_MAKE_PROGRAM="ninja"
    $env:CMAKE_FIND_ROOT_PATH="$(Split-Path -Path $(Get-Command magick).Path -Parent)"
    ```
- Build using cmake: `cmake --workflow --preset remaster`
- You can find binaries and extra files for each game in `build/remaster/RelWithDebInfo`:
  - Tiberian Dawn mod is the `NCO_TD` folder
  - Red Alert mod is the `NCO_RA` folder
- To install your mod you can follow the `Manual Install (Windows)` steps on the [Install Remaster Mod](1a.Install-Remaster-Mod.md) page

## Docker

A full docker based build that targets Ubuntu is available in [scripts/docker/ubuntu.Dockerfile](https://github.com/djfdyuruiry/cnc-new-construction-options/blob/main/scripts/docker/ubuntu.Dockerfile).

**First, you must ensure:**

- Docker is installed and running (and `docker` is in your `PATH`)
- The current user has permission to run docker commands
- `git` is installed (and in your `PATH`)

**Steps:**

> **On Windows**: Use Git Bash to run the below steps (included with Git for Windows)

- Download [ubuntu.Dockerfile](https://github.com/djfdyuruiry/cnc-new-construction-options/raw/refs/heads/main/scripts/docker/ubuntu.Dockerfile) and [test-ubuntu-build.sh](https://github.com/djfdyuruiry/cnc-new-construction-options-fix/raw/refs/heads/main/scripts/docker/test-ubuntu-build.sh) to a directory
- Run `chmod +x test-ubuntu-build.sh`
- Run `./test-ubuntu-build.sh`
- Build output will be copied to `./bin`

> Note: Build can be re-ran after editing the script or the source code (see `./src` after running the script once)
