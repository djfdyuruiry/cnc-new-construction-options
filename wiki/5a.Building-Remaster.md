
Debug:

- Build DLL
- Deploy resources and DLL to Mods path
- Debug process, launched as shown below:
    
    ```bash
    <PATH_TO_REMASTERED_INSTALL>\InstanceServerG.exe GAME_INDEX=0 CLIENT_PORT=16000 RUN_AS_APP NO_AUTO_EXIT LAUNCH_FROM_CLIENT=
    ```

- Run game client:
    
    ```bash
    <PATH_TO_REMASTERED_INSTALL>\ClientG.exe GAME_INDEX=0 TIBERIANDAWN
    ```

- Note: on hitting breakpoints client will likely freeze/lock up. Restart after each breakpoint
